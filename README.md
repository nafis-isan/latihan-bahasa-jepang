# JapanKanji

JapanKanji adalah aplikasi web belajar bahasa Jepang berbahasa Indonesia. Materinya mencakup kanji, kosakata, hiragana dan katakana, tata bahasa, percakapan, serta latihan untuk persiapan JLPT.

## Cara membuka

Aplikasi ini berupa satu file HTML dan tidak memerlukan instalasi atau proses build:

1. Buka `japankanji_v1_6_5_pro.html` dengan browser modern seperti Chrome, Edge, atau Firefox.
2. Ikuti panduan awal, lalu pilih bagian yang ingin dipelajari dari navigasi di bagian bawah.

Sebagian fitur seperti pemuatan font dan pelafalan suara dapat bergantung pada dukungan browser atau koneksi internet. Fitur inti belajar dan latihan tersedia langsung dari file.

## Fitur utama

- **Materi:** kurikulum kanji bertahap, latihan hiragana dan katakana, daftar kanji, kosakata, bacaan pendek, menyimak, tata bahasa, serta percakapan.
- **Latihan:** kuis pilihan ganda dan mengetik untuk arti maupun bacaan kanji/kata, kuis cepat, kartu hafalan, dan remedial.
- **Sesi harian:** mengenalkan kanji baru dan menjadwalkan pengulangan dengan jeda.
- **Progres:** streak, XP, target belajar, tingkat penguasaan kanji, kalender 28 hari, ringkasan 7 hari, serta lencana pencapaian.
- **Misi harian:** dua misi berganti setiap hari. Misi yang selesai dapat diklaim untuk memperoleh 5 XP.
- **Peta perjalanan:** melihat kemajuan dan tahapan kurikulum JLPT N5, N4, serta Pengayaan.
- **Tampilan responsif:** antarmuka menyesuaikan layar ponsel maupun komputer, dengan pilihan tema dan ukuran huruf.

## Progres dan privasi

Progres disimpan di penyimpanan lokal browser pada perangkat yang digunakan. Data tidak otomatis tersinkron ke perangkat lain. Untuk memindahkan atau menyimpan progres, buka **Progres Belajar → Cadangkan / pulihkan data**, lalu salin kode cadangan atau unduh file jika browser mendukungnya. Simpan kode cadangan di tempat aman dan jangan membagikannya karena berisi data progres belajar.

Menghapus data situs/browser dapat menghapus progres lokal. Buat cadangan terlebih dahulu jika ingin menyimpannya.
